# Animazioni ai raggi X

Sito didattico in italiano con animazioni interattive per le scuole medie
(scienze, matematica, fisica). Usato dagli insegnanti sulla LIM e dagli studenti a casa.

## Prima di creare o modificare un argomento
Leggi per intero:
- docs/GUIDA-STILE.md
- docs/STRUTTURA-ARGOMENTO.md

Rispettale senza eccezioni. Se una regola non funziona per un caso concreto,
proponi di cambiare la guida invece di fare un'eccezione.

## Regole fisse
- Tutti i testi visibili sono in italiano.
- Nessuna risorsa esterna (font, librerie, immagini): tutto nel repo.
- Solo illustrazioni SVG originali.
- Un nuovo argomento parte sempre con `stato: bozza`; non impostare mai
  `stato: pubblicato` senza che `revisionato_da` sia compilato.
- Stack: Astro, deploy statico su GitHub Pages.
